# 🪖 YOLO Helmet Detection

A custom object detection project built with **YOLO11n** to detect whether motorcycle riders are wearing helmets.

The model detects two classes:

* **With Helmet**
* **Without Helmet**

The project demonstrates a complete object detection workflow, including dataset preparation, model training, evaluation, and real-image inference.

---

## 📌 Project Overview

The goal of this project is to build an object detection model capable of identifying helmet usage in images of motorcycle riders.

The project covers the complete YOLO workflow:

**Dataset → Training → Validation → Evaluation → Prediction**

The model was trained using a custom helmet detection dataset and evaluated on unseen test images.

## 📊 Test Performance

The trained model was evaluated on the test dataset.

| Metric    |      Score |
| --------- | ---------: |
| mAP@50    | **79.82%** |
| mAP@50-95 | **43.69%** |
| Precision | **84.90%** |
| Recall    | **69.06%** |

These results show that the model can successfully detect helmet usage while maintaining good precision on the test dataset.

Detailed evaluation plots and metrics are available in the [`results/`](results/) directory.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ajmal335/YOLO_Helmet_Detection.git
cd YOLO_Helmet_Detection
```

Create and activate the Conda environment:

```bash
conda create -n ai-engineer python=3.11
conda activate ai-engineer
```

Install dependencies:

```bash
pip install -r requirements.txt
```
